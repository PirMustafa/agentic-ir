## 1 Problem Introduction
Agentic AI refers to a class of artificial intelligence systems designed to operate with autonomy, pursue complex goals, and adaptively interact with dynamic environments[cite: 1]. Unlike traditional AI models that passively respond to input, agentic systems proactively seek information, decompose tasks, devise strategies, and execute actions often through the integration of tools, APIs, and external data sources[cite: 1]. These systems ingest and analyze vast amounts of data, enabling them to make decisions with limited supervision and act independently across diverse contexts, including robotics, software development, and virtual assistance[cite: 1]. Agentic AI combines the generative and flexible capabilities of large language models (LLMs) with the structured accuracy of traditional programming paradigms[cite: 1].

While generative AI is primarily reactive—producing content such as text, images, or code in response to prompts—agentic AI exhibits agency, meaning it can autonomously plan and execute actions toward a goal using techniques such as natural language processing, machine learning, reinforcement learning, and knowledge representation[cite: 1]. In the domain of Information Retrieval (IR), the integration of agentic capabilities represents a paradigm shift from static document ranking to interactive, context-aware, and user-aligned retrieval systems[cite: 1]. Agentic IR agents can dynamically refine queries, traverse knowledge graphs, interact with databases, validate factual information, and even invoke external APIs to augment results[cite: 1]. For instance, such a system might autonomously break down a complex information need into sub-questions, retrieve relevant documents from distributed sources, and synthesize a coherent answer[cite: 1]. These capabilities are actively being explored in current AI research and industry initiatives, such as OpenAI's AutoGPT and Microsoft's Jarvis, which aim to extend the reasoning and planning abilities of LLMs into more autonomous, decision-making agents[cite: 1].

## 2 State-of-the-Art
The integration of agentic AI into information retrieval (IR) systems has catalyzed the development of autonomous agents capable of dynamic reasoning, tool utilization, and adaptive interaction with complex data environments[cite: 1].

* **Agentic Information Retrieval (Agentic IR):** This conceptual framework reimagines IR by leveraging large language models (LLMs) as autonomous agents[cite: 1]. These agents are designed to perform multi-step reasoning, employ retrieval-augmented generation (RAG), and utilize tools such as web search and code execution to fulfill complex information needs[cite: 1]. The approach emphasizes techniques like prompt engineering, reflection, and multi-agent collaboration to enhance retrieval performance and adaptability[cite: 1].
* **Agentic Reasoning Framework:** This framework enhances LLM reasoning by integrating external tool-using agents[cite: 1]. It introduces a "Mind Map" agent that constructs structured knowledge graphs to track logical relationships, improving deductive reasoning[cite: 1]. By incorporating web search and coding agents, the system enables real-time retrieval and computational analysis, demonstrating significant improvements in complex scientific reasoning tasks[cite: 1].
* **PaperQA:** Performs information retrieval across full-text scientific articles, assesses the relevance of sources, and synthesizes answers[cite: 1]. It surpasses existing LLMs and agents on science QA benchmarks and introduces LitQA, a benchmark requiring retrieval and synthesis from full-text scientific papers[cite: 1].
* **CollEX:** This multimodal agentic RAG system facilitates interactive exploration of extensive scientific collections[cite: 1]. By employing large vision-language models as multimodal agents within a chat interface, CollEX supports curiosity-driven exploration, integrating textual and visual modalities to aid educators and researchers in accessing diverse scientific records[cite: 1].
* **Agentic Contextual Retrieval in Telecommunications:** In the realm of intelligent communications and networking, agentic AI enables AI-driven agents to perceive, reason, decide, and act within dynamic networking environments[cite: 1]. By integrating multi-source retrieval, structured reasoning, and self-reflective validation, agentic contextual retrieval frameworks enhance decision-making in telecom applications, such as network planning and resource allocation[cite: 1].

These advancements illustrate the transformative potential of agentic AI in information retrieval, enabling systems to move beyond static query-response models toward dynamic, context-aware, and goal-directed information access[cite: 1].

### Possible Thesis Extension
The exam project can be extended into a Master's thesis with several advanced research directions[cite: 1]. Some examples of possible Master's thesis directions are explained in detail below[cite: 1].

* **Agentic Query Decomposition for Spatio-Temporal Analysis**
  * **Approach:** Designing an agentic query planner that autonomously decomposes complex, time-series Earth observation requests into a sequence of targeted retrieval subtasks (e.g., "identify deforestation hotspots, then retrieve seasonal change imagery")[cite: 1].
  * **Application:** Users pose high-level, spatio-temporal questions (e.g., "Track urban growth and vegetative health in the Po Valley over the last decade"), and the agent orchestrates multi-step searches, combining CBIR, change detection, and metadata queries[cite: 1].
  * **Method:**
    * Implement a planning agent based on an LLM with hierarchical task decomposition[cite: 1].
    * Integrate temporal retrieval modules that call different archives/APIs for each time slice[cite: 1].
    * Use a tool-invocation manager to coordinate CBIR, change detection, and multi-modal retrieval agents in sequence[cite: 1].
* **Tool-Augmented Agentic Retrieval with Geo-Analytics**
  * **Approach:** Embedding an agentic orchestration layer that dynamically selects and invokes specialized geo-analytics tools (e.g., NDVI calculators, DEM processors, climate model APIs) within the retrieval pipeline [1, 6].
  * **Application:** A researcher asks, "Show areas of significant vegetation stress correlated with elevation changes," and the agent fetches imagery, runs analytics, and synthesizes results[cite: 1].
  * **Method:**
    * Develop a tool registry mapping LLM tool-calls to geo-processing functions (e.g., QGIS scripts, API endpoints)[cite: 1].
    * Implement real-time API connectors for on-the-fly computation (e.g., Google Earth Engine)[cite: 1].
    * Enable chain-of-thought prompts in the LLM to determine when to call each geo-tool and how to integrate outputs[cite: 1].
* **Self-Reflective Fact-Checking in Multi-Modal Retrieval**
  * **Approach:** Incorporating a self-validation agent that cross-references retrieved satellite images and metadata against external authoritative sources (e.g., land-use registries, scientific publications) before presenting results[cite: 1].
  * **Application:** When asked, "Verify recent flood extent in the Danube Delta," the system retrieves imagery, then autonomously validates the observations against hydrological reports and machine-read publications[cite: 1].
  * **Method:**
    * Implement multi-source cross-verification routines using both RAG and structured-data APIs[cite: 1].
    * Use an LLM-based confidence scoring module that triggers additional searches for low-confidence findings[cite: 1].
    * Present a fact-check summary that includes provenance annotations and uncertainty estimates[cite: 1].
* **Agentic AI Systems for Software Vulnerabilities**
  * **Approach:** Deploying an autonomous vulnerability agent that continuously audits software artifacts, reasons about potential threats, and proposes mitigations by simulating adversarial behaviors and consulting exploit databases[cite: 1].
  * **Application:** When tasked with "Identify exploitable logic flaws in a legacy authentication module," the system inspects the code, tests multiple execution paths, compares outputs with expected invariants, and consults CVE databases to validate its findings[cite: 1].
  * **Method:**
    * Leverage code-aware LLMs to interpret software semantics and identify risky patterns across language boundaries[cite: 1].
    * Employ simulation-based probing to test exploit chains, guided by reinforcement learning and symbolic execution[cite: 1].
    * Integrate a patch synthesis module that drafts secure code replacements, referencing past vulnerability resolutions[cite: 1].
